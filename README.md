# AppifyHub · Homebrew Tap

[Homebrew](https://brew.sh/) formulae for [AppifyHub](https://www.appifyhub.com/).

## Using the tap

Install Homebrew using its [official instructions](https://docs.brew.sh/Installation), then add this tap:

```sh
brew tap appifyhub/tap
```

For installing, updating and removing packages, follow the [Homebrew documentation](https://docs.brew.sh/Manpage). Fully qualified formula names use `appifyhub/tap/` as their prefix.

## Adding or removing projects

To add a project, submit a pull request with its formula in `Formula/<project>.rb`, following the official [formula cookbook](https://docs.brew.sh/Formula-Cookbook). To remove a project, submit a pull request deleting its formula.
